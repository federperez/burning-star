BURNING STAR — DESIGN TO DEFY
================================

Versión independiente en HTML, CSS y JavaScript puro.

ARCHIVOS
- index.html: página principal.
- styles.css: diseño y responsive.
- script.js: menú, señal, formulario y partículas.
- assets/: banner y emblema oficiales.
- fonts/: Oxanium, Space Grotesk y sus licencias.

USO LOCAL
Abrí index.html con cualquier navegador moderno.

PUBLICACIÓN
Subí la carpeta completa conservando su estructura.
No requiere instalación, compilación, Node.js ni dependencias.
